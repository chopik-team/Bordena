# Безопасность данных Bordena

Bordena W 1.0 работает локально. Ошибки и предложения относятся к проекту
Станислава Смирнова / CHOPIK Team, а не к автору Doska.

Официальный репозиторий: https://github.com/chopik-team/Bordena. Не отправляйте личные
заметки, резервные копии, ключи и WebView2 профиль в публичные отчёты. Для сообщения
об уязвимости без публикации персональных данных используйте контакт команды:
https://t.me/cho_pik1. Не прикладывайте базу пользователя к issue.

Пакеты обновлений и их метаданные проверяются подписью закреплённого ключа,
размером, SHA-256 и SemVer. Подпись пакета не заменяет Windows Authenticode.
Состояние проверки релиза и оставшиеся ограничения публикуются в релизном отчёте.

При проблеме сохранения оставьте приложение открытым и сделайте внешнюю копию,
если экспорт доступен. Не редактируйте непрозрачные файлы IndexedDB вручную.

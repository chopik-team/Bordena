# Bordena W 1.0

Bordena — локальное приложение CHOPIK Team для проектов, задач и планирования на **Windows 10/11 x64**. Основная работа не требует интернета, сервера или аккаунта. Автор Bordena — **Станислав Смирнов**.

## Возможности

- Рабочие пространства, папки и доски: свободная компоновка, матрица, таблица и «Путь к цели» (Goal Path).
- Карточки с Markdown, чек-листами, локальными вложениями, приоритетами, цветами и сроками.
- Общий календарь и пользовательские календари; день, неделя, месяц, год и список. Рабочие блоки, повторения, перенос планирования и график занятых часов.
- Связанные доски и явно включаемые правила прогресса и автоматизации.
- Поиск Ctrl+K, темы Light/Dark/System, RU/EN, компактность, Focus и необязательные вкладки.
- Bordena JSON, предварительный просмотр восстановления и локальные резервные копии.

## Установка

Официальный репозиторий: [chopik-team/Bordena](https://github.com/chopik-team/Bordena).
Проверенный установщик появится в [GitHub Releases](https://github.com/chopik-team/Bordena/releases) после прохождения релизной проверки. Наличие исходников не означает, что публичный релиз уже опубликован.

Основной файл: `Bordena-W1.0-Windows-x64-Setup.exe`. Node.js, Rust и исходники пользователю не нужны. При отсутствии Microsoft WebView2 установщик использует штатную установку runtime; для этого первоначально нужен интернет. После установки Bordena работает офлайн.

## Данные и обновления

Пользовательские проекты хранятся отдельно от заменяемых файлов приложения. Идентификатор остаётся `team.chopik.bordena`. Перед обновлением сохраните изменения, сделайте резервную копию в настройках и закройте Bordena.

Прямая установка и CHOPIK Launcher используют один официальный источник — GitHub Releases. План доставки: подпись метаданных и пакета, проверка версии, размера и SHA-256 перед запуском NSIS. В Bordena нет второго фонового механизма обновления. Фактическое состояние внедрения и проверок — в [релизном отчёте](docs/BORDENA_W10_RELEASE_REPORT.md).

## Разработка

Стек: React + TypeScript + Tauri 2 + Rust. Требуются Node.js 24, pnpm 11, Rust и Windows MSVC/SDK. `pnpm install --frozen-lockfile`, затем `dev.bat` запускает встроенное настольное приложение. `Bordena.bat` запускает готовую локальную release-сборку.

Проверки: `pnpm check:version`, `pnpm check:i18n`, `pnpm type-check`, `pnpm lint`, `pnpm test`, `pnpm build`; Rust и native QA — по [чек-листу](docs/BORDENA_W10_RELEASE_CHECKLIST.md). Тестирование только в изолированных профилях. [Нумерация](docs/VERSIONING.md), [история](CHANGELOG.md). Для участия создавайте issue или PR с описанием проблемы и проверкой сохранности данных; не включайте личные базы, ключи и профили.

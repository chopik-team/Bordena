# Клиент Bordena

React + TypeScript интерфейс собственного локального Windows-приложения.
Хост — Tauri 2; обычный запуск из корня через dev.bat, интерфейс встроен в exe.
Код, используемый из Doska, находится в собственных пакетах @bordena/*;
происхождение и авторство сохранены в корневых LICENSE и NOTICE.md.

- components/app — оболочка, страницы и контекст доски.
- components/navigation — вкладки, избранное, локальный поиск и создание доски.
- components/deck — обычная доска, свободные секции и матрица.
- components/card и card-panel — переиспользуемые карточки и Markdown-редактор.
- lib/adapters — локальная IndexedDB, файлы и платформенные порты.
- lib/exchange — JSON/ZIP, проверка, preview и backup/restore.
- lib/layout-workspace.ts — безопасные изменения конфигурации представлений.

Серверные маршруты, регистрация, PWA и удалённые обновления исключены.
Полная документация и результаты проверок находятся в ../../docs.

# Bordena W 1.0

- Windows 10/11 x64, React + TypeScript + Tauri 2 + Rust. Не переносить на Python/Java.
- Автор Bordena: Станислав Смирнов, CHOPIK Team. Часть исходного кода — Doska,
  автор Margarita Romenkova, MIT. Сохранять copyright и уведомления зависимостей.
- Только локальная основная работа. Без обязательного сервера, аккаунтов, облака,
  телеметрии. Никакого браузерного запуска для пользователя. По утверждённому W 1.0
  доставка обновлений разрешена через проверяемые GitHub Releases и CHOPIK Launcher;
  основная работа Bordena остаётся офлайн, встроенный updater не добавляется.
- Обычный способ тестирования изменений — dev.bat: пересборка embedded debug app.
- Интерфейс и руководство — RU/EN через @bordena/i18n; язык системы: ru → ru, остальные → en. Программные имена — English.
- Использовать утверждённый PNG Bordena; не возвращать якорь и старые ресурсы Doska.
- Переиспользовать существующие UI-компоненты, не добавлять ненужный дизайн.
- Доски/Markdown/чек-листы/вложения/теги/приоритеты/drag-and-drop должны сохраняться.
- Native profile изолирован через team.chopik.bordena и явный WebView2 data directory.
- Автотесты запускаются только на временных `.tools/qa-*` профилях. Не читать
  и не изменять реальные профили Doska/Kanri и рабочие пользовательские доски.
- Изменения импорта/восстановления требуют проверки формата, контрольных сумм,
  конфликтов, preview, проверенного backup перед заменой и атомарной записи.
- Проверки: pnpm type-check; pnpm lint; pnpm test; pnpm build; native embedded QA.
- Не коммитить автоматически. Не отправлять изменения в upstream Doska, не force-push.
- Основной запуск — dev.bat. Windows release build разрешён новым master task;
  установщик допускается после QA. Публикация в chopik-team/Bordena разрешена
  утверждённым W 1.0 master task только после обязательных релизных проверок.
- Указывать приблизительный процент завершённости задания в каждом обновлении и итоговом ответе.
- Статусы PASS давать только после реальной проверки. Незавершённое явно отмечать PENDING.

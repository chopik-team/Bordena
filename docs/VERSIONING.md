# Нумерация Bordena

Текущая версия продукта — **Bordena W 1.0**, техническая версия Windows/SemVer — **1.0.0**.
Публичные версии используют W; исторические предварительные версии — AW.
Соответствие: 0.8.2 → AW 0.82; 0.8.1 → AW 0.81; 0.8.0 → AW 0.8;
0.7.1 → AW 0.71; 0.7.0 → AW 0.7; 0.6.0 → AW 0.6. Полная таблица — releases/version-history.json.

Единый источник — `package.json` в корне. Tauri читает его напрямую, интерфейс,
генераторы руководства и уведомлений о лицензиях используют ту же версию.
Отображение задаётся packages/utils/src/versions.ts. Для неизвестных исторических версий
не придумывается сокращённое число: это сохраняет однозначность. Канал и сравнение
обновлений используют SemVer, а не строку AW/W. Prerelease относится к Dev.
Версии приватных пакетов проекта и Cargo согласованы с корневой версией.
Проверка согласованности — `pnpm check:version`.

Версии JSON, схемы IndexedDB, идентификаторы, зависимости и пользовательские данные
не меняются при переименовании версии продукта. Имена прежних архивов, файлов
отчётов, сценариев QA и исходные результаты проверок сохранены для воспроизводимости.
Старая версия внутри архивного установщика описывает именно тот исторический файл.

Запуск актуальной Windows-сборки — `Bordena.bat`; пересборка при разработке — `dev.bat`.
